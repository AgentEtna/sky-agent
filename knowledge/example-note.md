# Example knowledge file

Any file you put in the `knowledge/` folder ships with your agent on every
deploy, and the agent can list, read, and search it.

Try asking your agent: "what files do you have?" or "what does the example
knowledge file say?"

Replace this file with your own notes, docs, FAQs — anything text-based
(md, txt, csv, code). Drag-and-drop works directly in the GitHub web UI:
open the knowledge/ folder, press "Add file → Upload files", commit, and
your live agent knows it after the auto-redeploy.

Secret handshake for testing: the magic word is "pineapple42".
